# Commodities Price Prediction Using Machine Learning Regression

## Project Overview

This project focuses on predicting commodity prices using machine learning regression techniques.

Historical commodity market data is collected and analyzed to identify price trends and patterns. The processed data is then used to train and evaluate different regression models for predicting future commodity prices.

The project compares multiple machine learning algorithms based on their predictive performance and provides an interactive interface to visualize historical prices, model performance, and predicted prices.

## Objectives

- Collect historical commodity price data using Yahoo Finance.
- Perform Exploratory Data Analysis (EDA) to understand market trends.
- Apply data preprocessing and feature engineering techniques.
- Develop machine learning regression models for price prediction.
- Evaluate and compare models using regression performance metrics.
- Build an interactive commodity price prediction interface.

## Project Phases

The project is divided into the following implementation phases:

1. *Environment Setup:* Installing the required libraries and configuring the development environment.
2. *Data Collection:* Obtaining historical commodity market data.
3. *Exploratory Data Analysis:* Analyzing price movements, distributions, and trends.
4. *Feature Engineering:* Creating useful features from historical market data.
5. *Model Development:* Implementing and training regression algorithms.
6. *Model Evaluation:* Comparing model performance using evaluation metrics.
7. *Prediction Interface:* Developing an interactive dashboard for predictions.
8. *Documentation:* Preparing project documentation and implementation details.
9. *Final Presentation and Submission:* Presenting the project and submitting the completed implementation.

## Project Workflow

The project follows a structured machine learning workflow:

1. Collect historical commodity data.
2. Clean and preprocess the collected dataset.
3. Perform exploratory data analysis.
4. Generate additional features using historical price information.
5. Split the data into training and testing sets.
6. Train different regression models.
7. Evaluate and compare model predictions.
8. Display prediction results through the Streamlit dashboard.
