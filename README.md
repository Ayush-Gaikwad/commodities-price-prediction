# Commodities Price Prediction Using Machine Learning Regression

## Project Overview

This project focuses on predicting commodity prices and returns using machine learning regression techniques.

Historical commodity market data will be collected, analyzed, and used to train regression models.

The project aims to compare different machine learning algorithms and evaluate their predictive performance using appropriate regression metrics.

## Objectives

- Collect historical commodity price data.
- Perform exploratory data analysis (EDA).
- Apply feature engineering techniques.
- Train machine learning regression models.
- Compare model performance using MAE, RMSE, and R².
- Develop a commodity price prediction interface.
